Documentation

ripwire is a high-throughput code intelligence engine and context router for AI coding agents and developers. It indexes 24 programming languages via Tree-Sitter to construct directed call graphs, calculate symbol impact via Personalized PageRank, slice intra-procedural dataflow, and enforce pre-commit quality gates.

Installation

Homebrew (macOS & Linux)

brew install casonadams/tap/ripwire

Cargo

cargo install ripwire

rw CLI Reference

The rw binary offers both direct flag-based execution and structured workflow subcommands.

# General repository call graph map and PageRank ranking
rw .

# Top maintenance hotspots (code churn * cognitive complexity)
rw --hotspots

# Shotgun Surgery co-change mining
rw --cochange [FILE]

# Caller compatibility check after symbol edit
rw --edit-check "symbol_name"

# Map affected test files for changed symbols
rw --affected "src/lib.rs"

# Measure code quality delta regressions against git HEAD
rw --quality-delta

# ARISE variable dataflow slicing (forward, backward, both)
rw --slice "function_name:var_name" --slice-flow fwd

# Export interactive HTML call graph visualization
rw . --html callgraph.html

Subcommands

Categorized workflow groups for targeted developer investigations:

# Exploration and task-scoped orientation
rw orient [PATH] --for <TASK>

# Call graph navigation (callers, callees, transitive impact)
rw navigate [PATH] --symbol <NAME> --impact

# Pre-commit verification gates
rw gate [PATH] --edit-check <SYM> --affected <PATH> --quality-delta

# Maintenance hotspots and code complexity metrics
rw metrics [PATH] --hotspots

# Launch stdio Model Context Protocol (MCP) server
rw mcp

Pre-Commit Verification Gates

Ripwire integrates directly into pre-commit workflows and CI/CD pipelines to prevent regressions:

  • Contract Breakage (--edit-check): Verifies if modifying a symbol changes parameter counts or visibility modifiers, identifying all 1-hop callers that become incompatible.
  • Test Reachability (--affected): Traverses transitive reverse call graph edges to surface exactly which test files reach the changed symbols or files.
  • Quality Delta (--quality-delta): Compares the working tree against git HEAD across 10 defect vectors (cognitive complexity, cyclomatic complexity, dead code, duplicates, and arity breaks).

33 Model Context Protocol (MCP) Tools

Ripwire embeds a native JSON-RPC stdio server exposing 33 context routing tools directly to AI coding agents like Claude Desktop, OpenCode, and Omp:

explore Orientation
One-call task orientation: ranked symbols, signatures, 1-hop callers, and field notes under a deterministic token budget.
impact Analysis
Calculates the transitive blast radius of a symbol across all reverse callers, ranked by PageRank.
quality_delta Quality Gate
Evaluates pre-PR regressions against git HEAD across 10 quality metrics.
edit_check Quality Gate
Checks whether a symbol contract (arity + visibility) broke against git HEAD and surfaces incompatible callers.
affected Test Routing
Identifies tests transitively reaching modified files and symbols.
slice Dataflow
Intra-procedural def-use variable slicing (ARISE algorithm) following value flow forward or backward.
cochange Git Mining
Mines Fowler's Shotgun Surgery historical git co-change partners.
replace_symbol_body / insert_before / insert_after Atomic Edits
Safe, atomic AST-based symbol body replacement and code insertion.
doc_drift Verification
Identifies claims in markdown files that no longer match the live index.

Rust Library API

Embed ripwire directly into your Rust developer tools, custom CLI utilities, or AI agent runtimes: 

// Cargo.toml
// [dependencies]
// ripwire = "0.1"

use ripwire::{ingest_in_memory_files, Graph, Interner, Lang, PageRankConfig};

fn main() {
    let interner = Interner::new();
    let files = [("src/main.rs", Lang::Rust, b"fn main() { run(); }\nfn run() {}" as &[u8])];
    let ingest = ingest_in_memory_files(&files, &interner);

    let graph = Graph::from_ingest(&ingest, &interner);
    let pr = ripwire::page_rank(&graph.matrix, PageRankConfig::default());

    println!("Indexed {} symbols and {} edges", ingest.symbols.len(), graph.matrix.nnz());
}
