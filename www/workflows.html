PRACTICAL GUIDE · 6 PRIMARY WORKFLOWS

When, Where, & Why to Use ripwire

ripwire is engineered around high-impact workflows: from landing cold in a foreign codebase to surgical test execution and automated CI/CD PR verification.

🧭 1. Orientation & Scoping: Landing Cold in a Repository
Scoping
When & Where

First time inspecting an unfamiliar codebase, onboarding new engineers, or scoping a task for an AI coding agent without blowing prompt budgets.

# Architecture map of top 200 ranked symbols by Personalized PageRank rw . --top-k=200 # File-by-file structural inventory showing top 3 symbols per file rw . --tree # Task-lens relevance ranking: retrieves ranked declarations relevant to a goal rw . --for="implement user authentication" # Export interactive, self-contained SVG/HTML call graph to open in browser rw . --html=graph.html --color-by=community
Why & Key Benefits
  • Zero Hallucinated Dependencies: Emits an in-context AST schema dictionary defining minified keys (t, n, sc, k, c).
  • Prompt Token Economy: Emits shown="K" truncation disclosures so models know absence in a top-slice does not mean absence in the repo.
  • Instantaneous Speed: Renders entire repository topologies in ~25 milliseconds.
🔍 2. Navigation & Blast Radius: Safe Refactoring & Impact Analysis
Refactoring
When & Where

Before modifying a function signature, during incident investigation to trace caller paths, or when measuring the blast radius of modifying a core data model.

# Query direct 1-hop callers that depend on a symbol rw . --callers="Interner::len" # Query outgoing dependencies called by a function rw . --callees="ingest_files" # Transitive reachability graph: full blast radius across the whole codebase rw . --impact="Interner" # Local ego-graph neighborhood (depth=1..3, fanout=32) rw . --around="execute_query" --around-depth=2 --around-fanout=16 # Shortest directed call path between two functions rw . --path="parse,serialize" # ARISE intra-procedural def-use variable dataflow slicing (forward/backward) rw . --slice="compute:x" --slice-flow=both
Why & Key Benefits
  • Zero Surprise Breakages: Answers "Can I safely change this?" with exact static call graph reachability instead of text search guesses.
  • Ambiguity Disclosure: Tags ambiguous call sites with prov="split" when a call cannot be resolved to a single unique definition.
  • Deep Disambiguation: Supports flexible selectors (bare_name, Scope::name, file:name, file::Scope::name).
🛡️ 3. Pre-Commit & PR Safety Gates: Zero Broken Contracts
Safety Gate
When & Where

In local Git pre-commit hooks, pre-push scripts, or automated CI/CD pull request verification gates before merging code.

# Verify caller compatibility after modifying a symbol contract rw . --edit-check="symbol_name" # Transitive reachability mapping to affected test suites rw . --affected="src/lib.rs" # Pre-PR gate: names tests to run and untested blast radius (exits with code 4) rw . --test-gate # Situational awareness report for working tree diff: blast radius, tests, co-change rw . --situ # Assess whether a symbol can be safely deleted without breaking callers rw . --safe-delete="Interner::len" # Measure code quality regressions against git HEAD across 10 facets rw . --quality-delta
Why & Key Benefits
  • Surgical Test Execution: Identifies the exact test files that transitively reach your changes, running a 5-second test subset instead of a 20-minute suite.
  • Contract Breakage Prevention: Catches parameter count changes and visibility regressions across all direct callers before you commit.
  • Fowler's Shotgun Surgery Protection: Surfaces companion files historically edited with your diff that you may have forgotten to update.
📈 4. Code Health & Technical Debt Auditing
Architecture
When & Where

During sprint refactoring cycles, technical debt burn-downs, and architectural cleanup reviews.

# Detect internal functions with zero incoming callers across the repository rw . --dead-code # Rank repository files by maintenance risk (churn * cognitive complexity) rw . --hotspots # Detect AST code clones and near-miss duplicates (Type-1, Type-2, Type-3) rw . --clones --min-tokens=40 # Mine historical Git co-change coupling to identify hidden file coupling rw . --cochange # Partition call graph into cohesive modules via Louvain community detection rw . --communities # Discover symbols referenced in code but never defined (stdlib & external packages) rw . --external-surface
Why & Key Benefits
  • Data-Driven Focus: Prioritizes refactoring where maintenance churn intersects with elevated cognitive complexity.
  • Safe Dead-Code Pruning: Pinpoints zero-caller functions with mathematical certainty without manual grep sweeps.
  • Architectural Clarity: Detects tangled module boundaries and cyclic dependencies.
🤖 5. Deep Inspection & Agent Context Delivery
AI Context
When & Where

Extracting exact function implementations for LLM prompts, debugging compiler error messages, or multi-query agent pipelines.

# Expand full source body of symbols and callee signatures in CDATA XML rw . --expand="Symbol::new" # Outline control-flow skeletons of symbols (loops, branches, declarations) rw . --outline="Interner::intern" # Pack source bodies of the top N highest PageRank symbols rw . --pack-top-n=5 # Map compiler error / stack trace frames directly onto indexed symbols rw . --from-trace=error.log # Execute up to 16 heterogeneous sub-queries in a single turn rw . --batch=queries.txt # Structured JSON output for navigation queries rw . --callers="Interner::len" --json # Launch native stdio Model Context Protocol (MCP) server for coding agents rw mcp # Install 18 pre-packaged ripwire agent skills to ~/.agents/skills (or custom path) rw --add-skills
Why & Key Benefits
  • Precision Context Bundles: Extracts only relevant symbol bodies into CDATA blocks, conserving prompt token budgets.
  • Batching Economy: --batch executes up to 16 queries in a single turn, eliminating agent tool-call round-trip latency.
  • Native Agent Protocol: 33 built-in MCP tools accessible over stdio for Claude Desktop, Cursor, and Omp.
  • Instant Agent Skills: --add-skills provisions 18 standardized skills and active manifest into ~/.agents/skills for zero-configuration onboarding.
⚙️ 6. Continuous Integration (CI) & Automated PR Gates
CI / CD
When & Where

In automated GitHub Actions, GitLab CI, or Jenkins pipelines running on every pull request and merge to trunk.

# PR Gate: names tests to run and untested blast radius (exits 4 on violation) rw . --test-gate # Quality Regression Gate: checks quality regressions against base branch / HEAD rw . --quality-delta # Upstream Parity Validation: verifies 1:1 input/output equivalence across 20 commands make validate REPO=.
Why & Key Benefits
  • Automated Merge Blocking: Fails PR jobs automatically (exit code 4 on --test-gate or non-zero on --quality-delta) before untested code or architectural rot merges.
  • Sub-50ms Execution: Fast in-memory static analysis executes in milliseconds, eliminating slow CI runner bottlenecks.
  • Upstream Parity Enforcement: make validate runs continuous 20-command verification matrices against upstream specifications.
